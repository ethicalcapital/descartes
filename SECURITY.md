# Security policy

Descartes is experimental verification software. No release currently has a supported security maintenance window. A successful quotation check establishes byte occurrence, not truth, completeness, context, or safety.

Please report suspected vulnerabilities privately through this repository's GitHub **Security → Report a vulnerability** form. Do not post exploit details, credentials, private evidence, or personal information in public issues or pull requests. Include affected revision, reproduction steps using synthetic data, observed impact, and any suggested mitigation.

Maintainers will assess reports before coordinating a fix and disclosure. No response-time guarantee or bounty is offered.
