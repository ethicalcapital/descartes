# Descartes

Descartes is part of [Praxis](https://praxis-reader.ethical-capital.workers.dev), an open-source project from Ethical Capital. It develops inspectable, deterministic verification of claims against pinned evidence.

This is the public contribution home. The reviewed source snapshot and synchronization mechanism are still being prepared. No code release or verified research bundle is published here yet.

The proposed quotation standard is: every quotation occurs exactly once, byte for byte, in its pinned evidence text. When evidence text is derived, verifying its recorded recipe against the pinned original is an additional obligation. A quote match alone does not establish that obligation, factual truth, or editorial adequacy.

See CONTRIBUTING.md for contributions and SECURITY.md for private vulnerability reports.

## How the Praxis suite fits together

[Praxis](https://praxis-reader.ethical-capital.workers.dev) aims to support informed, accountable stewardship of our planet’s shared
resources by connecting activist groups and capital markets through constructive
disagreement. Inspectable evidence, reasoning and revision help participants
understand and challenge one another’s claims while preserving attribution,
context and independent judgment.
[Ethical Capital](https://ethicic.com) develops and uses the suite.

| Part | Role | Availability |
|---|---|---|
| [Praxis public reader](https://praxis-reader.ethical-capital.workers.dev) | Read published research and inspect its supporting material | Public reader available; source repository is not public yet |
| [Descartes](https://github.com/ethicalcapital/descartes) | Extract attributed, evidence-backed claims and check their evidence bytes and structure | Public contribution home available; source mirror is being prepared |
| Rawls | Make ethical frameworks, affected parties, tolerances and evaluation reasoning inspectable | Planned module; public repository forthcoming |
| Arendt | Support public association, response and accountable action | Planned module; public repository not yet verified |

The intended flow is **sources → Descartes claims → Rawls evaluations →
Arendt association, response and accountable action**, coordinated by Praxis. Rawls and Arendt
are future capabilities, not working dependencies of today's Descartes
checker. A quote match proves a relationship between bytes; it does not
establish truth, fairness, consensus or an editorial endorsement. Current
research can be published before those future modules exist.

Start with the Praxis reader for research, or Descartes's contribution
instructions for improvements to evidence verification. Public module links
will be added as their repositories become available.
