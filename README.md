# Descartes

Descartes is part of Praxis, an open-source project from Ethical Capital. It develops inspectable, deterministic verification of claims against pinned evidence.

This is the public contribution home. The reviewed source snapshot and synchronization mechanism are still being prepared. No code release or verified research bundle is published here yet.

The proposed quotation standard is: every quotation occurs exactly once, byte for byte, in its pinned evidence text. When evidence text is derived, verifying its recorded recipe against the pinned original is an additional obligation. A quote match alone does not establish that obligation, factual truth, or editorial adequacy.

See CONTRIBUTING.md for contributions and SECURITY.md for private vulnerability reports.
