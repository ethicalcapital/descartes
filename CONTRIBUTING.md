# Contributing

Issues and pull requests are welcome here. This public repository is the contribution surface for Descartes; the maintainer integrates accepted changes into the authoritative source before publishing updates here.

Keep changes focused. Explain the problem, intended behavior, validation performed, and remaining limitations. Use synthetic examples; do not submit credentials, private research, restricted source material, or generated stores. You must have permission to contribute the material you submit.

Report vulnerabilities privately using SECURITY.md. Ordinary bugs and documentation corrections belong in issues or pull requests.

The source mirror is being prepared. Until the reviewed source snapshot is published, this repository contains publication and contribution information only. It does not yet provide a buildable release or automatic synchronization.
